# Vision produit

## Problème

Git versionne très bien du code, mais ne standardise ni la preuve, ni la donnée,
ni la provenance, ni la reproductibilité des résultats.

## Solution

OpenForge ajoute une couche de confiance au-dessus de Git :

- type d'artefact explicite ;
- dépendances déclarées ;
- exécution déterministe ;
- résultats signés ;
- comparaison entre versions ;
- réputation fondée sur les reproductions réussies.

## Utilisateurs

- chercheurs ;
- développeurs IA ;
- quant traders ;
- analystes ;
- entreprises ;
- organismes publics ;
- communautés open source.

## Différenciation

OpenForge ne se limite pas à héberger des fichiers. Il exécute, vérifie,
compare et certifie les artefacts.
